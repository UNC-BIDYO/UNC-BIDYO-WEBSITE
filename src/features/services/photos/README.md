# Services photos

One folder per service panel. The **first image by file name** is used as the panel photo.

| Folder              | Panel            |
| ------------------- | ---------------- |
| `event-coverage/`   | Event Coverage   |
| `photoshoots/`      | Photoshoots      |
| `video-production/` | Video Production |

- Panels are tall on phones and stretch wide when opened on desktop, so pick photos whose
  subject sits near the **center** (the edges get cropped).
- At least 1280px wide. The build converts them to WebP at 400–1280px.
- The panel text sits on the bottom, over a dark gradient: busy bottoms are fine.

Titles, summaries and the expanded details are in `../serviceList.ts`.
